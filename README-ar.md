# حل تحدي Frontend Mentor - Testimonials Grid Section

هذا هو حلي لتحدي [Testimonials grid section](https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7) من منصة Frontend Mentor. تساعد هذه التحديات على تحسين مهارات البرمجة وتطوير الواجهات عبر مشاريع عملية.

## نظرة عامة

### التحدي
يجب أن يكون المستخدم قادراً على:
- عرض التخطيط المثالي للموقع والتكيف بسلاسة مع مختلف احجام الشاشات (تصميم متجاوب).

### التقنيات المستخدمة
- هيكلة باستخدام HTML5 الدلالي
- متغيرات CSS (Custom Properties)
- تقنية CSS Grid و Flexbox
- منهجية التصميم ابدأ بالهاتف (Mobile-first)
